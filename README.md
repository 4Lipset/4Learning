
# Learning Production Designer (Demo)

This Streamlit app helps educators generate full unit plans and detailed daily lesson plans aligned to real-world issues, SEL competencies, and academic standards.

## Features

- Generate a complete unit + scaffolded lesson plans
- Align lessons with state or Common Core standards
- Incorporate SEL via the CASEL framework
- Build toward a public-facing final product
- Export full plan to DOCX

## Run the app

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

1. Push these files to a GitHub repo
2. Go to https://streamlit.io/cloud and link your repo
3. Set `app.py` as the main file
