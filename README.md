
# Learning Production Designer (Demo)

This app helps educators generate full units and scaffolded lesson plans aligned to real-world issues, SEL competencies, and academic standards.

## Features
- Weekly and daily lesson scaffolding
- Embedded standards (Common Core, CA, TX, NY, Other)
- Public-facing final product with rubric and checklist
- Export to DOCX

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud
Push this folder to GitHub, then deploy at https://streamlit.io/cloud
