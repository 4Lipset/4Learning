
# Learning Production Designer GPT

This app helps educators design and refine interdisciplinary, SEL-aligned, project-based learning experiences using AI-powered generation and editing.

## Features

- Generate a full unit plan + daily lesson plans
- Align to state standards, CASEL SEL competencies, and civic outcomes
- Choose production environments (e.g. studio, media lab)
- Download plans as DOCX or TXT
- Suggest improvements and refine with AI
- Manually edit plan content in-app

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy via Streamlit Cloud

1. Push this project to GitHub.
2. Connect it at https://streamlit.io/cloud
3. Set `app.py` as the main file.
