
# Learning Production Designer (Demo)

A Streamlit app that generates complete unit plans and detailed lesson plans aligned with SEL, academic standards, and culminating public-facing student projects.

## Features

- Unit and daily lesson scaffolding
- Integration with Common Core and state standards (CA, TX, NY, Other)
- Public-facing final product design with rubric and checklist
- Export to DOCX

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

Push to GitHub and deploy from https://streamlit.io/cloud using `app.py` as your main entry file.
