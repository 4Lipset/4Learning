
# Learning Production Designer GPT

A Streamlit app to help educators design project-based, equity-centered learning experiences grounded in:

- CASEL-aligned SEL
- Civic engagement
- Standards alignment (A-G, TEKS, CCSS, etc.)
- Student agency and identity work

## Run the app

```bash
pip install -r requirements.txt
streamlit run app.py
```

Or upload this to Streamlit Cloud!
