
# Learning Production GPT – Final Version

This Streamlit app generates full units and lesson plans aligned with SEL, academic standards, and public-facing exhibition projects.

## Features

- Weekly and daily plans scaffolded to final performance
- SEL integration (CASEL)
- Core and interdisciplinary state standards
- Public event planning support
- Export as DOCX, TXT, or PDF

## Local Use

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud

Push to GitHub, connect at https://streamlit.io/cloud and set `app.py` as the main file.
