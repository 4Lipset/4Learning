
# Learning Production GPT

This Streamlit app generates full units and lesson plans aligned with SEL, academic standards (state/Common Core), and culminating public-facing student projects.

## Features

- Standards-aligned weekly & daily lessons
- SEL (CASEL) integration
- Multi-format downloads (DOCX, PDF)
- Exhibition prep scaffolding
- Customizable by subject, standards, and tools

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud Deployment

Push to GitHub, connect at https://streamlit.io/cloud and set `app.py` as the main file.
