
# Learning Production GPT

This is a Streamlit web app that helps educators design interdisciplinary, project-based learning units grounded in social justice, civic engagement, and SEL.

## How to Run

1. Install dependencies:
```
pip install -r requirements.txt
```

2. Run the app:
```
streamlit run app.py
```

## Deploy to Streamlit Cloud

1. Push this repo to GitHub.
2. Visit https://streamlit.io/cloud and connect your repo.
3. Choose `app.py` as the main file, and deploy!
