
# Learning Production Designer (Final Version)

This Streamlit app generates complete unit and lesson plans aligned to SEL, interdisciplinary academic standards, and public-facing performance.

## Highlights

- Core + interdisciplinary standards (custom by state)
- CASEL SEL skills and weekly closures
- Exhibition checklist and prep sequencing
- Linked templates for real-world events
- Exportable DOCX

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

Push to GitHub, then launch at https://streamlit.io/cloud. Use `app.py` as the entry file.
